# Day 9 Variables + Quoting
Write a Bash script that creates two variables: one storing the username and the other storing the path to the /etc/passwd file. Then, display the values ​​of both variables.  
 [See script](main.sh)  
Quotation marks and variables in Bash:  
"$var" — the variable value enclosed in quotation marks. Variables are expanded, and spaces within the value do not separate arguments.
'$var' — literally the text $var. The variable is not expanded.  
$var — the variable value without quotation marks. It usually works, but spaces and special characters can cause problems.
