# Day 8 Bash Functions

A function is a reusable block of commands that performs a specific task.  

Syntax:  
```
function_name() {  
    commands  
}  
```
Functions can receive arguments, which are accessed using $1, $2, etc.  

The function is executed by writing its name followed by the required arguments.  

## Task

Write a Bash script containing a function named `check_file` that checks whether a given file exists. If the file exists, the script should display the message "exists" along with the file's name.
