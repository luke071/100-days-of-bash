# Arithmetic Operators
| Operator | Meaning | Example |
|----------|---------|---------|
| + | Addition | (( x = 5 + 3 )) |
| - | Subtraction | (( x = 10 - 4 )) |
| * | Multiplication | (( x = 3 * 7 )) |
| / | Integer division | (( x = 10 / 3 )) |
| % | Modulo | (( x = 10 % 3 )) |
| == | Equal | (( x == 5 )) |
| != | Not equal | (( x != 3 )) |
| > | Greater than | (( x > 10 )) |
| < | Less than | (( x < 10 )) |
| >= | Greater or equal | (( x >= 10 )) |
| <= | Less or equal | (( x <= 10 )) |
| ++var / var++ | Increment | (( i++ )) |
| --var / var-- | Decrement | (( --i )) |
| += | Add and assign | (( x += 2 )) |
| -= | Subtract and assign | (( x -= 1 )) |
