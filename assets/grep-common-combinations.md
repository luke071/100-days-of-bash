# Most Commonly Used grep Combinations
| Combination | Description |
|------------|-------------|
| grep -i    | Ignores case (case‑insensitive search) |
| grep -v    | Shows lines that do *not* match |
| grep -w    | Matches whole words only |
| grep -n    | Displays line numbers |
| grep -r    | Recursively searches directories |
| grep -c    | Counts matching lines |
| grep -E    | Uses extended regular expressions (ERE) |
| grep -l    | Prints only filenames with matches |
| grep -H    | Always shows the filename in output |
| grep -o    | Prints only the matched part of the line |
| grep -qx   | Checks if the file contains exactly one line equal to the pattern |
| grep -iq   | Quiet case‑insensitive check (no output, exit code only) |
| grep -rn   | Recursive search with line numbers |
| grep -rI   | Recursive search, ignoring binary files |
| grep -Eo   | Extended regex + print only the matched part |
