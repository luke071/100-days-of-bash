# Day 23 Backup
## Tar Basic Syntax  

tar [options] archive_name files 

Common options: 

-c    create an archive  
-x    extract an archive  
-t    list archive contents  
-f    specify the archive filename  
-v    verbose output  
-z    use gzip compression  
-j    use bzip2 compression  
-J    use xz compression
